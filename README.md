# Ля Букет — сайт цветочного салона

Альметьевск, ул. Мусы Джалиля, 22 · +7 917 285 61 68

Статический сайт без сборки: `index.html` (витрина) и `admin.html` (панель администратора).

## Что внутри
- **Первый экран** — 3D-галерея из фото букетов (Three.js): карточки парят, следуют за курсором, разлетаются при прокрутке, по клику открывают букет. Живой пастельный фон и переливающиеся лепестки.
- **Коллекция шедевров** — 3D-карусель хитов (тянуть мышью/пальцем).
- **Каталог** — 56 букетов с исходного сайта, фильтры по категориям, поиск, сортировка, карточка товара.
- **Корзина** — заказ отправляется сообщением в WhatsApp или Telegram.
- **О салоне, отзывы, адрес с картой Яндекса и маршрутом.**
- **Админ-панель** (`/admin.html`, ссылка «Вход для администратора» в подвале): добавить / изменить / скрыть / удалить букет, загрузить фото (сжимается автоматически), отметить «Хит», поменять порядок, изменить телефон, часы работы, адрес, объявление над шапкой. Резервная копия каталога — меню «Ещё».

Пароль администратора по умолчанию: `buket2026`. Смените его в `js/config.js` (там же инструкция).

## Запуск на компьютере
```
node serve.mjs
```
и откройте http://localhost:5180 (двойной клик по index.html не сработает — браузер блокирует модули с диска).

## Публикация
Папку можно выложить на Vercel / Netlify / любой хостинг как есть (`vercel.json` уже настроен).

## Важно: где хранятся изменения из админки
По умолчанию — **в браузере администратора** (localStorage). Покупатели видят исходный каталог.
Чтобы правки видели все посетители, подключите бесплатную базу Supabase:
1. Создайте проект на supabase.com.
2. SQL Editor → выполните `supabase/schema.sql`.
3. Authentication → Users → Add user — email и пароль администратора.
4. Project Settings → API: скопируйте `Project URL` и `anon public key` в `SUPABASE` в `js/config.js`.

После этого вход в админку — по email и паролю, фото загружаются в облако, а стартовый каталог зальётся в базу автоматически при первом входе.
